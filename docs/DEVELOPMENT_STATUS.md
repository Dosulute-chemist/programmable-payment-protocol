## Recent changes

- Documented the current contract features and limitations in the root README.
- Added resolver-mode dispute settlement with full refund, full release, or partial awards.
- Added cancellation request and recipient acceptance flow.
- Changed escrow settlement to credit claimable balances, allowing users to withdraw to an alternate recipient address.
- Added per-asset accounting for locked escrow and claimable balances, plus a solvency view.
- Added adversarial tests for unauthorized actions, repeated settlement, partial dispute accounting, rejecting recipients, fee-on-transfer tokens, dishonest adapters, and input/output swap accounting.
- Changed large escrow/trade/payment records to use explicit getters or field assignments where needed to avoid oversized autogenerated getters and compiler stack pressure.
- Bundled trade execution parameters into request structs to reduce stack pressure.
- Added an external-audit scope and threat-model brief.

## Status definitions

- **Implemented:** code exists.
- **Compiled:** CI build completed successfully for a specific commit.
- **Tested:** the stated test suite passed for that commit.
- **Testnet deployed:** deployed to a named test network with recorded addresses.
- **Audited:** an independent audit report exists for the exact release code.

These labels must not be used interchangeably.
